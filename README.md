# AIORI-3-HACKATHON-PROJECTS
This repository will contain the code and resources for the AIORI-3 hackathon that will be developed during the AIORI-3
## Problem Statement
PS027: Browser-based IPv6 Readiness Auditor. A tool that loads websites in a real browser on IPv4-only and IPv6-only networks, records every dependency, and shows where each failed resource broke (DNS, TCP, TLS or HTTP).
